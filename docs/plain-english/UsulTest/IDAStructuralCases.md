# UsulTest.IDAStructuralCases in Plain English

Source: [`formal/lean/UsulTest/IDAStructuralCases.lean`](../../../formal/lean/UsulTest/IDAStructuralCases.lean)

This module connects three bounded examples from the accepted ACT-08 roadmap
to the existing registry, context, substitution, and application checkers.

The agency-revocation candidate keeps its actual unresolved mandate and
manifestation roles. Guessing an existing operand sort cannot resolve either
declaration. Two descriptions can have the same action core while their
attributed qualifications produce different report-observation results.
Those reports remain separate from truth in the supplied synthetic history.

Two omission opportunities share a kind and interval but have different
occurrence identities. Each has a positive application with exact supplied
test certificates and grants. Participant substitution preserves the occurrence.
Cross-occurrence certificates, duplicate tokens, stale snapshots, and missing
evidence or grants fail the existing admission checks.

## Named proof contracts

| Declarations | What they establish |
| --- | --- |
| `revoke_unresolved` | No registry/envelope pair resolves to this definition while its mandate role remains unresolved |
| `registry_controls` | The nine declared registry variants have their specified diagnostic outcomes |
| `substitution_retains_occurrence`, `substitution_retains_profile`, `two_stage_inquiry` | Typed substitution preserves the fixed occurrence and profile; staged interpretation agrees with composed reindexing |
| `projection_retains_occurrence`, `projection_view_contract`, `distinct_occurrences_remain_distinct` | Full scoped projection retains occurrence identity and evaluator output; different occurrences cannot collapse into one such projection |
| `cross_occurrence_certificate_rejected`, `changed_context_receipt_rejected` | Exact admission rejects a certificate from another occurrence, and changed context authority prevents old-receipt replay |
| `occurrence_matrix`, `qualification_matrix` | The two finite families have the declared outputs under the actual implementation |
| `fresh_qualification_authority_admits` | Every declared qualification mask has a positive reconstruction under matching supplied test authority |
| `native_models`, `native_conditional_sound` | Each native occurrence/substitution instance has a history satisfying its premises and conditional conclusion |
| `hidden_exception_same_core`, `same_kind_distinct_occurrences` | Shared kind/core can hide different observation outcomes or different occurrence identities |

These are nine general obligations and eight finite fixture witnesses, each
required again at an explicit proposition type in the contract module.

The exported matrix contains 81 rows and 585 cells. Its separate contract module
pins the named propositions. The independent Quint model and host gate compare
the finite results and exercise adverse controls. These are synthetic,
same-profile examples; they do not admit a fiqh interpretation or provide a
general migration or source-authentication service.

the exact case domains, trust assumptions, and reproduction commands.
