# UsulTest.NususTable in Plain English

Source: [`formal/lean/UsulTest/NususTable.lean`](../../../formal/lean/UsulTest/NususTable.lean)

The foundation ḥadīth corpus passes through the kernel's ḥadīth gate exactly as graded: sound reports are admitted as dalīl (proof) and weak ones are refused. The table also pins the purity rulings for three bodily discharges. The file is generated by `python -m usul_corpus signature` from `corpus/nusus/foundation.json` and the dossier glossary.

## 1. The ḥadīth gate (13 checks)

`Usul.Seam.admitted` takes a ḥadīth offered as naṣṣ (text) with al-Albānī's verdict. It admits it only if the verdict makes it a ḥujja (binding proof). Each guard cites the collection and the Irwāʾ al-Ghalīl number.

| Check | Plain English |
| --- | --- |
| `admitted ⟨.nass, .sahih⟩ == true` (11) | Ṣaḥīḥ (sound) reports are admitted, e.g. H-ali-madhy (Muslim 303), H-bahr-tahur (Abū Dāwūd 83). |
| `admitted ⟨.nass, .daifJiddan⟩ == false` | H-shufa-iqal, very weak, is refused. |
| `admitted ⟨.nass, .daif⟩ == false` | H-siwak-ashi, weak, is refused. |

The two refused reports are ones al-Saʿdī names as not sound.

## 2. Bodily discharges (6 checks)

`Usul.Tahara.Kharij` records two facts for each discharge: is it najis (impure), and what purification it obliges.

| Discharge | `najis` | `obliges` | Plain English |
| --- | --- | --- | --- |
| maniyy (المني, semen) | false | `.ghusl` | Pure, but requires a full bath. |
| madhy (المذي, pre-seminal fluid) | true | `.wudu` | Impure; requires ablution. |
| wady (الودي, post-urinary fluid) | true | `.wudu` | Impure; requires ablution. |

## In one line

Only ḥadīth graded sound reach the kernel as proof, and the purity rules for maniyy, madhy and wady come out as the corpus records them.
