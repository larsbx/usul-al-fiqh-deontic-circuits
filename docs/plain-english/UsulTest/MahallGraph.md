# UsulTest.MahallGraph in Plain English

Source: [`formal/lean/UsulTest/MahallGraph.lean`](../../../formal/lean/UsulTest/MahallGraph.lean)

This file holds the concrete label graph: every case's maḥall (what it rules on), the label tree, and which canonical texts define which labels. It checks the graph against `Usul.Mahall`. It is generated by `python -m usul_corpus mahall` from `corpus/mahall`.

Ids are short:
- `r013.f010` is Ibn Rajab's qāʿida 13, farʿ 10, and `l043.f001` is Ibn al-Laḥḥām's.
- A text is numbered `n0001` onwards. `corpus/mahall/graph.json` gives each number's reference and quoted words.

| Check | Plain English |
| --- | --- |
| `data.rootedB 16` | Every label climbs to its chapter (bāb) in at most 16 steps. The tree has no cycles and no dangling labels. |
| `data.exactB 16 q S G` (one per qāʿida, 159) | The labels its furūʿ (cases) fall under, closed upwards, are exactly `S`. The texts grounding it are exactly `G`. By `exactB_sound` this is a statement about the relations `footprint` and `grounds` themselves, not only about the computation. |
