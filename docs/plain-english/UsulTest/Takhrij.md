# UsulTest.Takhrij in Plain English

Source: [`formal/lean/UsulTest/Takhrij.lean`](../../../formal/lean/UsulTest/Takhrij.lean)

Each annotated farʿ (a derived case reported in the books) gets the ruling its qāʿida (legal maxim) predicts when the formal reading is run. The suite holds 1,039 generated guards, one per farʿ. A single mismatch fails the Lean build, so takhrīj (deriving case rulings from principles) stays checked as the readings change.

## 1. How a guard works

- **Annotation**: a corpus record in `corpus/takhrij/*.json` that names a farʿ, the reading (encoder) that covers it, the inputs read from the farʿ's own words, and the ruling the book states.
- **Guard**: a comment naming the farʿ and its status, then `#guard (reading inputs) == expected`. Lean evaluates it at build time.
- **`derivable`**: the reading yields the stated ruling outright. 441 guards.
- **`genuine_ikhtilaf`**: the scholars disagree (ikhtilāf), and the guard checks the madhhab position, the school's own view. The other positions stay recorded in the corpus. 598 guards.
- **Encoding errors**: a recorded mismatch would be guarded with `!=`. None remain in the current file.
- The file is generated by `python -m usul_corpus takhrij` and must not be edited by hand. Second derivations of the same farʿ live apart, in `UsulTest.TakhrijCo`.

## 2. Where the cases come from

| Source | Guards | Notes |
| --- | --- | --- |
| Ibn Rajab, *Taqrīr al-Qawāʿid* | 1,015 | Cases under 144 of his qawāʿid, from Q1 to Q160; 425 derivable, 590 ikhtilāf. |
| Ibn al-Laḥḥām, *al-Qawāʿid wa'l-Fawāʾid* | 21 | Qawāʿid 43, 52, 53, 54 and 61, on command, generality and occasion; 13 derivable, 8 ikhtilāf. |
| Kawsaj, *Masāʾil Aḥmad* | 1 | A substitute is used when the original is impossible. |
| Ibn Qudāma, *al-ʿUmda* | 1 | The same substitute rule. |
| al-Lajna al-Dāʾima, *Fatāwā* | 2 | Two fatāwā decided by the order of the maqāṣid (`Maqasid.taqdim`): life before relief from hardship, and a complement of lineage before a need. |
| Al-Ḥajjāwī, *Zād al-Mustaqniʿ* | 1 | A wage is owed without stipulation (`RajabA2.wageWithoutStipulation`). |

## 3. Which readings the guards exercise

| Readings | Guards | What they encode |
| --- | --- | --- |
| `Usul.Readings.RajabA1`–`RajabA25` | 550 | Ibn Rajab's qawāʿid read one by one, 13 to 25 guards per module. |
| `Usul.Readings.Mubashara`, `Concordance` | 10 | Direct act vs cause in liability (Q127), and two equivalent readings of one qāʿida. |
| `Usul.Readings.Maqasid` | 2 | The order of the maqāṣid in tarjīḥ (al-Kawkab). |
| `Usul.Refinements` | 384 | Earlier readings extended by the input a case exposed, each with a default that returns the old reading; e.g. lots, aṣl vs ẓāhir, recourse. |
| `Usul.Kulliyyat` | 45 | General maxims, e.g. dependent establishment (Q50) and one performance discharging an act (Q41). |
| `Usul.Muamalat` | 26 | Transaction maxims. |
| `Usul.Dalala` | 17 | Generality of wording and its occasion (Ibn al-Laḥḥām). |
| `Usul.Sadi` | 7 | Al-Saʿdī's maxims applied directly. |

The two busiest encoders are `Refinements.allocationFull` (47 guards, who gets a disputed thing) and `Refinements.zahirPrevails` (40 guards, when the apparent overrides the presumption).

## 4. Representative guards

| Check | Plain English |
| --- | --- |
| `RajabA1.rescission true true == .withRemedy` (Q60) | Rescinding a permissible contract that harms someone is allowed only with the harm made good. |
| `Refinements.allocationFull false false false == .lot` (Q160) | No known entitled party and an indivisible thing: draw lots. |
| `Refinements.zahirPrevails .zann .qat true == true` (Q159) | Decisive apparent evidence (qaṭʿ) beats a presumption held only on probability (ẓann). |
| `RajabA23.grandchildCountsAsChild true false true == true` (Q153) | For a ruling of the first kind, the grandchild takes the child's ruling even with the child present. |
| `Refinements.errorExcused false false == true` (Q6) | An act done in error stands when no one else's right is attached and there was no negligence. |
| `Dalala.coversBeyondSabab true false false == false` (Ibn al-Laḥḥām Q61) | A wording that is not general does not reach past its occasion. |
| `Dalala.IsGeneralIn .definiteAl .affirmation true == false` (Ibn al-Laḥḥām Q52) | A noun with *al-* in an affirmation is not general when it refers to something known (ʿahd). |
| `Sadi.useSubstitute false == true` | When the original is impossible, the substitute is used. |

Many farʿ share inputs, so identical guard lines recur; each still stands for a distinct reported case.

## In one line

Over a thousand reported cases, mostly from Ibn Rajab, are each run through their formal maxim at build time, and the build fails if any comes out different from the book or, in disputed cases, from the madhhab.
