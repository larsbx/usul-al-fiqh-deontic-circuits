# UsulTest.FatawaTakhrij in Plain English

Source: [`formal/lean/UsulTest/FatawaTakhrij.lean`](../../../formal/lean/UsulTest/FatawaTakhrij.lean)

Each of 68 annotated fatwā cases from IslamQA is replayed through the formal reading it was matched to. Where the case is derivable or a genuine ikhtilāf (disagreement), the reading must return the madhhab's answer. Where the annotation recorded an encoding error, the reading must *not* return the fatwā's answer.

## 1. How a guard reads

- **Farʿ (`islamqa.<id>.f<n>`)**: one sub-ruling extracted from a fatwā, named by question number and position.
- **`derivable`** (63 cases): the reading reproduces the fatwā's ruling, checked with `==`.
- **`genuine_ikhtilaf`** (2 cases): scholars differ; the guard checks the madhhab position with `==`.
- **`encoding_error`** (3 cases): the inputs as annotated do not give the fatwā's answer; the guard pins that mismatch with `!=`.

The file is generated by `python -m usul_corpus fatawa-takhrij` from `corpus/fatawa/takhrij/*.json`.

## 2. Aṣl against ẓāhir (24 cases)

`Usul.Refinements.zahirPrevails asl zahir amara` decides whether the ẓāhir (the apparent state) overrides the aṣl (the presumed baseline). It does so when the ẓāhir is strictly stronger, or equally strong and the matter has amāra (indicators). Grades run wahm < shakk < ẓann < qaṭʿ (fancy, doubt, likelihood, certainty).

| Check | Plain English |
| --- | --- |
| `zahirPrevails .zann .qat true == true` (7) | A certain ẓāhir beats a likely baseline. |
| `zahirPrevails .zann .shakk false == false` (11) | Mere doubt never overturns the baseline. |
| `zahirPrevails .zann .shakk true == false` (3) | Doubt stays too weak even when indicators exist. |
| `zahirPrevails .zann .zann true == true` (1) | At equal strength, indicators tip it to the ẓāhir. |
| `zahirPrevails .zann .wahm _ == false` (2) | A fancy never overturns the baseline. |

## 3. Luqaṭa, found property (14 cases)

`Usul.Refinements.luqata yearPassed ownable` gives the outcome for a found item. Before the year of announcement it is held. After it, the finder owns it if it is ownable, else it goes to charity.

| Check | Plain English |
| --- | --- |
| `luqata true true == .finderOwns` (7, one of them ikhtilāf) | After a year, an ownable find becomes the finder's. |
| `luqata false true == .hold` (4) | Before the year ends, the finder only holds it. |
| `luqata true false != .hold` (3, encoding errors) | These fatwās keep the find held, e.g. a find in the Ḥaramayn, never ownable. The reading sends it to charity, so the contradiction is recorded. |

## 4. Liability for loss (18 cases)

`Usul.Muamalat.lossLiable hand transgressed negligent` answers whether the holder must compensate. A trustee (amīn) pays only after taʿaddī (transgression) or tafrīṭ (negligence). A wrongdoer pays regardless.

| Check | Plain English |
| --- | --- |
| `lossLiable .trustee false false == false` (7) | A trustee without fault owes nothing. |
| `lossLiable .trustee true false == true` (4) | Transgression makes the trustee liable. |
| `lossLiable .trustee false true == true` (5) | Negligence makes the trustee liable. |
| `lossLiable .wrongdoer _ false == true` (2) | A wrongdoer is liable with or without transgression. |

## 5. Unknown owner (12 cases)

`Usul.Muamalat.recipient ownerIdentifiable` names who receives returned property. An owner who cannot be identified is treated as non-existent.

| Check | Plain English |
| --- | --- |
| `recipient true == .owner` (7, one of them ikhtilāf) | Known owners get their property back. |
| `recipient false == .publicInterest` (5) | Otherwise it goes to public interest (maṣlaḥa). |

## In one line

Sixty-eight real fatwā sub-rulings are machine-checked against four formal readings, and the three known encoding mismatches are kept visible rather than hidden.
