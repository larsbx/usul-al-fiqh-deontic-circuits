# UsulTest.FatawaBank in Plain English

Source: [`formal/lean/UsulTest/FatawaBank.lean`](../../../formal/lean/UsulTest/FatawaBank.lean)

The Python fatwā reviewer keeps its own copies of three kernel definitions: the five statuses, the default reading of commands and prohibitions, and conflict resolution. These 30 checks prove that the copies compute exactly what the Lean definitions compute. The file is generated by `python -m usul_corpus bank-review` and is not edited by hand.

## 1. The five statuses

The aḥkām taklīfiyya (the five obligation statuses) are wājib (obligatory), mandūb (recommended), mubāḥ (permitted), makrūh (disliked) and ḥarām (forbidden). For each status the suite checks four things, 20 checks in all.

- **`Usul.Hukm.σ`**: the status of leaving the act. Leaving a wājib act is ḥarām, leaving a mandūb act is makrūh, and so on. Mubāḥ maps to itself.
- **`Usul.Hukm.mode`**: the kind of address. Wājib and mandūb are ṭalab al-fiʿl (a demand to do). Makrūh and ḥarām are ṭalab al-tark (a demand to refrain). Mubāḥ is takhyīr (a free choice).
- **`Usul.Hukm.binding`**: whether the demand is binding (ilzām). Only wājib and ḥarām are.
- **Binding prohibition**: the test "demand to refrain *and* binding" is true for ḥarām alone.

| Check | Plain English |
| --- | --- |
| `Usul.Hukm.σ .wajib == .haram` | Omitting an obligation is forbidden. |
| `Usul.Hukm.mode .makruh == .talabTark` | The disliked is a demand to refrain. |
| `Usul.Hukm.binding .mandub == false` | The recommended does not bind. |
| binding-prohibition test on `.haram` | Only ḥarām is a binding demand to refrain. |

## 2. The default reading of commands

- **`Usul.Dalala.amrStatus none == .wajib`**: an amr (command) with no qarīna (contextual indicator) means obligation.
- **`Usul.Dalala.nahyStatus none == .haram`**: a nahy (prohibition) with no qarīna means forbiddance.

## 3. Conflict resolution order

`Usul.resolve` settles a taʿāruḍ (conflict between proofs). It tries jamʿ (reconciling both), then naskh (abrogation), then tarjīḥ (preferring one), and otherwise tawaqquf (suspending judgement). The suite runs all eight combinations of which stages are available.

| Check | Plain English |
| --- | --- |
| jamʿ available (4 cases) → `.jam .wajib` | Reconciliation wins whenever it is possible. |
| no jamʿ, naskh available (2 cases) → `.naskh .haram` | Abrogation comes before preference. |
| only tarjīḥ → `.tarjih .mandub` | Preference is used only when nothing earlier applies. |
| nothing available → `.tawaqquf` | With no stage available, judgement is suspended. |

## In one line

The reviewer's Python mirrors of the five statuses, the bare-command defaults and the jamʿ → naskh → tarjīḥ → tawaqquf order agree with Lean on every input.
