# UsulTest.IDAContextContracts in Plain English

Source: [`formal/lean/UsulTest/IDAContextContracts.lean`](../../../formal/lean/UsulTest/IDAContextContracts.lean)

These examples state fixed proof obligations for unique and rigid resolution,
typed predicate arguments, exact binding, temporal identity, loss of
qualifications, and canonical typed encoding. Lean checks the imported proofs
against these statements.

The omission statements also pin the exact covered result, invariance under
unseen observations, and current snapshot binding.
